# Backend planejado

Este diretório reserva a arquitetura futura para o backend do Bitcoin Monitor AI.

Responsabilidades previstas:
- coletar preços do mercado em intervalos automáticos;
- aplicar regras de alerta em um serviço dedicado;
- expor endpoints para o app móvel;
- integrar com Firebase Cloud Messaging para push;
- armazenar histórico e análise de eventos de mercado.

A implementação real deste backend ainda não faz parte desta tarefa.
